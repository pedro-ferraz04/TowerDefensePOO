## Tower Defense em C++

Projeto da disciplina de Programação Orientada a Objetos (PUCRS, 2026/2), trabalho T1. 

Jogo de defesa de torre em modo texto, em que o jogador posiciona torres ao longo de um mapa 10x10 para impedir que inimigos alcancem a base.
Parte gráfica totalmente gerada em IA, não tinha ideia de como fazer.

## Como compilar e executar

O projeto usa um Makefile. Na pasta do projeto, execute:

```bash
make            
make run       
make clean     
```

**Versão em texto
```bash
g++ main_game.cpp -o main_game.exe
./main_game.exe
```
